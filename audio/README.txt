# Speakline Audio Directory
You can place local audio fallback files here:
- `lofi.mp3`: Default local lofi track fallback
- `intro.mp3`: Local spoken intro ("Speak fast and clear")

If these local files are not present, Speakline automatically falls back to:
- High-quality Creative Commons Lofi tracks hosted on Internet Archive (Centz - Lo-Fi Library LP)
- 24/7 Laut.fm Lofi Radio live stream
- Web SpeechSynthesis API for the voice intro prompt
